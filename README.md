## TechScript Showcase

```techscript
# Write plain English. Execute at native speed.
make name = ask "What is your name? "
say f"Hello, {name}! Welcome to TechScript"

each i in 1..10 {
    when i equals 5 { stop }
    say f"Count: {i}"
}
```

Highlights:
- Native Rust bytecode VM and compiler
- Studio IDE with AST and bytecode inspection
- Built-ins for math, crypto, fs, os, json, random, and date
- `use web` for website building and `use three_d` for quick 3D scenes
