## 🐉 TechScript Spotlight — Plain English Programming Language

<img src="./assets/techscript.svg?v=2" width="100%" alt="TechScript spotlight: a plain English programming language with a native Rust VM, TechScript Studio IDE, 150 plus built-ins, a web builder, a 3D module and one installer." />

**TechScript** is an open-source programming language engineered from the ground up with a native **Rust compiler and bytecode VM**. It gives humans plain-English syntax while executing at blistering native speeds.

```techscript
# Write plain English. Execute at native Rust speed.
make name = ask "What is your name? "
say f"Hello, {name}! Welcome to TechScript 🐉"

each i in 1..10 {
    when i equals 5 { stop }
    say f"Count: {i}"
}
```

<div align="center">

| Feature | Engineering Details |
|---|---|
| 🦀 **Native Rust VM** | High-performance bytecode VM & compiler written completely in Rust |
| 🖥️ **TechScript Studio** | Docking desktop IDE (`egui` + `egui_dock`) with live AST & bytecode inspector |
| ⚡ **150+ Built-ins** | Standard library including `math.*`, `crypto.*`, `fs.*`, `os.*`, `json.*`, `random.*`, `date.*` |
| 🌐 **WebBuilder & AppForge** | `use web` — construct responsive web interfaces without touching raw HTML boilerplate |
| 🎮 **3D Module** | `use three_d` — initialize interactive 3D WebGL scenes with simple declarative statements |
| 📦 **Universal Distribution** | Single zero-dependency installer + published directly on [PyPI](https://pypi.org/project/techscript-lang/) |

</div>
